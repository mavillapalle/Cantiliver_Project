# Experimental Setup

This folder contains the experimental setup used for the cantilever vibration analysis project.

## Experimental Components

- Cantilever beam
- Laser source
- Position Sensitive Detector (PSD)
- Signal conditioning circuit
- PicoScope oscilloscope for signal acquisition
- Computer with Python and Jupyter Notebook

## Experimental Procedure

1. The cantilever beam was fixed at one end.
2. The beam was excited to produce free vibration.
3. A laser beam was directed onto the free end of the cantilever.
4. The reflected laser spot was detected using the Position Sensitive Detector (PSD).
5. The PSD output was amplified using the signal conditioning circuit.
6. The analog signal was captured using the PicoScope.
7. The recorded data was exported as CSV files.
8. The data was analyzed in Python using FFT, peak detection, zero-crossing, and Hilbert transform methods to estimate the natural frequency and damping characteristics.
